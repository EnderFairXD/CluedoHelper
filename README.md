# Cluedo Helper

Una aplicación móvil desarrollada en Flutter para gestionar las cartas y automatizar las deducciones durante las partidas del juego de mesa Cluedo.

## Características Principales
* **Gestión de Jugadores:** Configuración de jugadores, personajes y cantidad de cartas iniciales.
* **Tablero Interactivo:** Matriz de deducción automática que cruza datos de sospechosos, armas y lugares.
* **Sistema Seguro:** Pantalla para mostrar cartas de forma privada a otros jugadores con bloqueo de retroceso accidental.
* **Historial de Acciones:** Capacidad para deshacer pasos si te equivocas al anotar.

## Cómo probar este proyecto
1. Asegúrate de tener instalado [Flutter](https://docs.flutter.dev/get-started/install).
2. Clona este repositorio: `git clone <tu-enlace-de-github>`
3. Descarga las dependencias ejecutando en la terminal: `flutter pub get`
4. Lanza la app en tu emulador o móvil conectado con: `flutter run`
